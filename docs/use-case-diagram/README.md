# VPLMQA UML Use Case Diagram

This folder contains the UML use case diagram for the VPLMQA platform.

- `vplmqa_use_case_diagram.puml`: editable PlantUML source.
- `vplmqa_use_case_diagram.svg`: ready-to-use visual diagram.

The diagram focuses on the main soutenance-friendly scope:

- authentication and password change,
- project/pages/settings management,
- feature import/manual writing,
- E2E generation and Playwright execution,
- AI analysis and tester validation,
- ticket creation and Azure DevOps synchronization,
- Figma/web extraction and design implementation comparison.
